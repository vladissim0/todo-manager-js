# Todo Manager 
## Application Purpose 

A console-based JavaScript application for managing a list of tasks. 

## Implemented Features 
* Add, view, complete, remove, and search tasks 
* Count total and completed tasks
*  Export and import tasks using JSON 
* Sort tasks by name and priority 
* Display task statistics 
* Validate user input

 ## Challenges Encountered 
 The main challenges were working with arrays of objects, understanding `return` values and variable scope. 
 ## Lessons Learned 
 I learned how to work with arrays and objects, use array methods such as `find()`, `filter()`, `findIndex()`, and `sort()`, work with JSON.
